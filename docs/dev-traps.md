# 运营陷阱清一屋(dev-facing,排斥在 evidence 各档之外的冷读入口)

> 每条都是本仓实际踩过的坑(原档已随过程证据清理,归档在 git history);此处一条一行,开工前扫一眼。
> 只收"操作层"陷阱——技能/流程纪律在各技能本体。

| 陷阱 | 落到地上的样子 | 一行解法 |
|---|---|---|
| `pkill -f <模式>` | 模式匹配到**自己的 shell**,一击自杀(本项目已 4 次:进程死了,分离任务成孤儿) | 分离任务启动时 `nohup … & echo $! > /tmp/xxx.pid`;停止只 `kill $(cat …pid)`;绝不 pkill -f |
| `pi -p "$(…)"` 超长参数 | `Argument list too long`——单参数上限 128KB(判分喂全量转写常撞) | 先压缩转写(工具结果行裁 200 字符);>100KB 就分段或判分脚本化 |
| 转写含 NUL | bash 命令替换静默吞输出,判分/解析"莫名"为空 | `tr -d '\0' < in > out` 再喂 |
| `--no-session` 与 `--session-dir` 并用 | 会话照跑但**不落盘**,事后无档可判(曾整轮 10 案假红) | --no-session 只配安全沙盒;凡要判分/取证,绝不加 |
| 长跑 `pi -p` 阻塞 | bash 工具超时杀管线,输出丢 | `nohup … > log 2>&1 &` + 间隔轮询 log/进程表 |
| 并发会话下跑门 | typecheck/test 偶发 exit 非零(另一个会话的构建/测试在跑) | 红了先看有无并发进程;**复跑一次再信红**(本项目一次假红险些记录为真) |
| 行为形盲测在活仓跑 | 盲测任务带全量工具 → 在产品仓真改码(P4 曾落一个虚构 PRD 提交,全清场才收) | 行为形盲测只在一次性克隆/fixture;盲测 prompt 不编造"之前讨论过"的上下文 |
| 判分只喂 transcript 前段 | `head -c 60KB` 把决定性证据切掉 → 假 FAIL 差点采信 | 喂全量或压缩转写;证据常在后半段 |
