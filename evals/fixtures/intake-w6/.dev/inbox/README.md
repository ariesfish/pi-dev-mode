# inbox

Unattributed intake for this repo's local tracker (`.dev/`, feature-first).
File a new report as `T-<next-id>.md`: report body first, then a `Status:`
line with its triage role (e.g. `Status: needs-triage`). When a report's
route settles, foster it into the owning feature's plan/todo under
`.dev/<slug>/`.
