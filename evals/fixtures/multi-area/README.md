# note-desktop

A desktop conversation client, ported from the paseo UI kit. Three surface
areas make up the product:

- **left rail** — `left-rail/rail.tsx`, workspace sidebar and IA
- **conversation surface** — `conversation/thread.tsx`, thinking rows, tool
  rows, markdown and mermaid rendering
- **composer** — `composer/input.tsx`, the input area

`reference.png` is the visual spec: the shipped UI must match it.

Files in this fixture: `README.md`, `reference.png`,
`left-rail/rail.tsx`, `conversation/thread.tsx`, `composer/input.tsx`.
